PowerFlex builds enterprise EV charging infrastructure. Miguel spent just over
five years there as a Senior Software Engineer, working across the stack on an
analytics-heavy charging management platform.

## Product and architecture ownership

- Worked directly with the VP of Engineering to build the MVP of the EV platform.
- Led front-end architecture for the enterprise EV charging management platform
  (React, TypeScript), with a focus on maintainability and performance as usage grew.
- Built and owned operational and analytics dashboards — real-time charger status,
  usage and reporting views — for a data-dense application.
- Built full-stack reporting features, owning the backend services behind them.

## Backend and distributed systems

- Built and maintained backend services in Node.js, FastAPI, and Flask inside an
  event-driven microservices architecture using NATS JetStream.
- Hands-on with API design and service-to-service communication patterns.
- Contributed to backend services that push firmware updates to physical EVSE chargers.

## Cross-team delivery

- Built a cross-team feature letting Amazon self-service their own site creation,
  using WebSockets for real-time progress updates in the UI.
- Translated Figma wireframes and design systems into production UIs, partnering
  with product managers, designers, and backend engineers to shape UX decisions
  rather than just implement them.

## Performance and tooling

- Diagnosed and resolved front-end performance bottlenecks: bundle size reduction,
  eliminating unnecessary re-renders, lazy loading and code splitting — improving
  responsiveness across high-traffic dashboard views.
- Maintained and extended CI/CD workflows in GitHub Actions for front-end
  deployment, including build and deploy configuration for new environments.
- Helped develop internal API documentation with Next.js.

## Mentorship

- Mentored five engineering interns and junior developers. All five were promoted
  to Engineer II, which he attributes to structured mentorship and technical guidance.
