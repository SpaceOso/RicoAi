MySmartSimulations built a healthcare training platform delivering tutorials,
simulations, and certification modules to medical professionals. Miguel owned the
front-end.

- Built the front-end for the healthcare training platform.
- Ported Unity3D simulations to JavaScript-based web applications, eliminating
  native runtime dependencies and expanding platform accessibility.
- Designed and implemented user interfaces from Photoshop mockups, collaborating
  with project managers and stakeholders throughout development cycles.
- Delivered highly interactive learning experiences using modern web technologies.

## Infrastructure work

The role also included hands-on IT and networking work:

- Helped set up a LAN at the labs where the products were used.
- Installed switches and routers in the office.
- Configured new computers and set up user accounts.
